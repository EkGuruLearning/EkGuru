Worksheets — free, printable, per language

A worksheet is a real page, not a PDF trap: ten languages, each with its own worksheet built from that course's own quiz bank. Pick a topic, make a sheet, print it. The questions are the ones the course itself practices — nothing here is filler, and the answer key stays on screen, because a printed worksheet is for writing, not for checking.

What every worksheet page gives you

  • A topic you choose. The sheet is made from the course's own question bank, so the practice matches the lessons.
  • Five to fifteen prompts. Multiple choice, fill the gap, translate, and re-order — the same types the course uses, laid out with room to write.
  • The answer key on screen only. It stays below the sheet for checking; the print never carries it, so the paper is for the learner's own writing.
  • A watermark and a source line. A printed sheet says where it came from: the page, the date, and ekguru.shop.

How a worksheet is printed

On the worksheet page, the Print button prints the sheet only — not the header, the menu, or the rest of the page. A subtle diagonal EKGURU mark and a source line (the page, the date, ekguru.shop) travel with it, so a sheet that leaves the site still says where it came from. If a page has no worksheet, the button says so instead of printing the lesson — a "Print Worksheet" button that prints a lesson would be a lie in the same file.

Every lesson here is free, and always will be.

No account, no paywall. The practice itself — every quiz, worksheet and drill — carries no ad at all; the pages around it sometimes do, and that is what keeps the lessons running. Keeping it free is the only thing this page asks of you.
