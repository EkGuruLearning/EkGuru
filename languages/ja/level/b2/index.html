Conditionals and plans

If: たら/れば/と

Three IFS! たべたら (if/when I eat — best all-rounder!), たべれば (if — elegant), たべると (whenever — automatic!). もし + any = extra-ifty: もしあめがふったら…!

WordSay itMeaning

ればrebaif (elegant)
とtowhenever (automatic)
もしmoshiif (emphasis)
でもdemobut / even
てもtemoeven if
のにnonialthough / despite
ためにtamenifor / in order to
たら (all-round if)

たべたら (if I eat), のんだら (if I drink), いったら (if I go). Past-stem + ら! あめがふったら、いきません (if it rains, I won't go). ても = even if: ふってもいきます!

past-stem + ら · て + も
WordSay itMeaning
あめがふったら、いきません。ame-ga futtara, ikimasen.If it rains, I won't go.
べんきょうしたら、わかります。benkyou-shitara, wakarimasu.If you study, you understand.
ふってもいきます!futtemo ikimasu!Even if it rains, I'll go!
Watch out:
  • Using たら for automatic truths — springs: おすとでます (push→comes out)!
  • Forgetting ら: ふったら with small っ + ら!

Respect and debate

Keigo basics: respect verbs

Respect language! いらっしゃる (honorific be/go/come), めしあがる (honorific eat), おっしゃる (honorific say). お + noun: おなまえ (your name), おかね. Elevate OTHERS, humble YOURSELF!

WordSay itMeaning
いらっしゃるirassharuhonorific be/go/come
めしあがるmeshiagaruhonorific eat
おっしゃるossharuhonorific say
くださるkudasaruhonorific give
もうすmousuhumble say
いたすitasuhumble do
お〜o-polite prefix
ご〜go-polite prefix (Chinese)
Elevate others, humble self

せんせいはいらっしゃいますか? (Is the teacher here?). I humbly: わたしがいたします (I'll do it). お + Japanese words (おちゃ), ご + Chinese words (ごはん)!

honorific for others · humble for self

  • Using いらっしゃる for YOURSELF — honorifics elevate OTHERS!

Debate connectors

Argue elegantly! しかし (however), だから (so/therefore), つまり (in other words), たとえば (for example), それに (besides), けっきょく (after all). Chain: たとえば…それに…だから…!

The B2 test — 10 items

The level test closes the level. Answers are shown; in the course player the same test decides whether the next level unlocks.

  1. translate into the languageSay: If it rains, I won't go

    Show the answer

    あめがふったら、いきません

  2. translate into the languageSay: Let's eat together!

    Show the answer

    いっしょにたべましょう

  3. choose'Is the teacher here? (respect)'

    1. せんせいはいますか
    2. せんせいはいらっしゃいますか
    3. せんせいがいたしますか
    4. せんせいはきますか
    Show the answer

    せんせいはいらっしゃいますか

  4. translate into Englishつまり、ちかてつがいいです!

    Show the answer

    In short, the subway is good!

  5. fill the gapふって___いきます! (even if)

    Show the answer

    も

  6. choose'I want to try sushi!'

    1. すしをたべます
    2. すしをたべてみたいです
    3. すしがたべたいです
    4. すしをたべたことがあります
    Show the answer

    すしをたべてみたいです

  7. put it in orderOrder: ふりました / ゆきが / とつぜん

    Show the answer

    とつぜんゆきがふりました

  8. say it out loudSay aloud: つまり、ちかてつがいいです!

    Show the answer

    つまり、ちかてつがいいです!

  9. fill the gapにほんへいく___です。 (plan)

    Show the answer

    つもり

  10. translate into the languageSay: Once upon a time, I went to Tokyo

    Show the answer

    むかしむかし、とうきょうへいきました

After B2: the B2+ checkpoint

B2+ is not a certificate — it is the half-step between this level and the next one, and it is on this site’s ladder because language schools use it. You are at B2+ when you can run a meeting, read a contract, disagree well. Get there by working the recall drills above and the review deck until nothing on this page surprises you, then open the B3 pages.
