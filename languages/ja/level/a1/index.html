A1, unit by unit

First words

Greetings: こんにちは

こんにちは (hello), おはよう (morning!), こんばんは (evening!). Meeting: はじめまして (nice to meet you) → わたしは + name + です → よろしくおねがいします (please treat me well)! Bow slightly!

ありがとうarigatouthanks

はじめまして、わたしはXです

わたしはゆきです = I am Yuki. は (wa) marks the topic, です ends politely. Finish with よろしくおねがいします = please be kind to me!

はじめまして、わたしは + name + です
WordSay itMeaning

ありがとう!arigatou!Thanks!
Watch out:
  • Saying わたしはは — one は is enough!
  • Skipping よろしく — introductions NEED it!

Names and おげんきですか

Ask names: おなまえは? (your name?) → わたしは…です. How are you: おげんきですか? → はい、げんきです! か turns anything into a question: ゆきですか? = Are you Yuki?

WordSay itMeaning
わたしwatashiI / me
あなたanatayou
なまえnamaename
おげんきですかo-genki desu kahow are you
げんきgenkifine / healthy
あなたはanata-waand you
くださいkudasaiplease (give me)
どうもdoumothanks (casual)
か = question mark in speech

げんきです (I'm fine) → げんきですか? (are you fine?). Just add か! おなまえは? = Your name? (polite). あなたは? = And you?

sentence + か?
WordSay itMeaning
おげんきですか?o-genki desu ka?How are you?
はい、げんきです!hai, genki desu!Yes, I'm fine!
おなまえは?o-namae-wa?Your name?
Watch out:
  • Raising voice WITHOUT か — questions need か!
  • Overusing あなた — names + さん are warmer!

です and counters

です and これ/それ/あれ

Point at things! これ (this-near-me), それ (that-near-you), あれ (that-far). これはほんです = This is a book. Negative: ほんじゃありません (it's not a book). Point and name the world!

WordSay itMeaning
これkorethis (near me)
それsorethat (near you)
あれarethat (far)
ほんhonbook
がっこうgakkouschool
くるまkurumacar
おおきいookiibig
ちいさいchiisaismall
これはXです · じゃありません

これはほんです (this is a book), それはくるまです (that is a car). Negative: これはほんじゃありません (this is not a book). Adjectives sit BEFORE nouns: おおきいほん!

これ/それ/あれ + は + X + です
WordSay itMeaning
これはほんです。kore-wa hon desu.This is a book.
それはくるまです。sore-wa kuruma desu.That is a car.
これはほんじゃありません。kore-wa hon-ja arimasen.This is not a book.
Watch out:
  • Saying これほんです without は — topic needs は!
  • Saying ほんですおおきい — adjectives go FIRST: おおきいほん!

Dialogue. Read it aloud twice — once for each speaker.

Counters: ひとつ、ふたつ

Count THINGS with つ! ひとつ (1 thing), ふたつ (2), みっつ (3) — up to とお (10). People: ひとり、ふたり. いくつ? = How many? ほんをみっつください! = Three books, please!

つ-counter for things

りんごをみっつ (3 apples), ほんをひとつ (1 book). を marks the object! いくつですか? = How many? Answer: みっつです!
