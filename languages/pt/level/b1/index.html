Stories and opinions

Stories: pretérito vs imperfeito

Two pasts! PRETÉRITO = finished actions (CHEGUEI = I arrived). IMPERFEITO = ongoing scenes (FAZIA SOL = it was sunny). Set scenes with imperfeito, fire events with pretérito.

Pretérito vs imperfeito: falei vs falava

FALEI = I spoke (done). FALAVA = I was speaking/used to speak (ongoing). -AR imperfeito: FALAVA, FALAVA, FALAVA — all the same! Weather, feelings, habits → imperfeito. Single events → pretérito.

pretérito (done) · imperfeito (was doing)
WordSay itMeaning
Cheguei às oito.sheh-GAY ahsh OY-too.I arrived at eight. (done)
Fazia sol.fah-ZEE-uh soh-oo.It was sunny. (scene)
Falava quando você chegou.fah-LAH-vah KWAHN-doo voh-SEH sheh-GOH.I was speaking when you arrived.
Watch out:
  • Using pretérito for weather: FAZIA sol, not FEZ sol.
  • Using imperfeito for arrivals: CHEGUEI, not CHEGAVA.

Comparisons: mais… do que, melhor

MAIS + adjective + DO QUE = more…than: MAIOR DO QUE = bigger than. O MELHOR = the best. MELHOR and PIOR never take MAIS — complete already!

mais/menos + adj + do que · melhor/pior
WordSay itMeaning

Acho que é pior.AH-shoo kee eh pee-OHR.I think it is worse.
Watch out:
  • Saying MAIS MELHOR — just MELHOR!
  • Forgetting DO QUE: MAIOR DO QUE, with DO QUE!

Real world

Work and formal you (o senhor)

At work, VOCÊ fits most people. For extra respect use O SENHOR (sir) / A SENHORA (madam) — with HE/SHE verb forms: O SENHOR FALA inglês? = Do you (formal) speak English?

O SENHOR: formal you uses he-forms

VOCÊ FALA (standard) vs O SENHOR FALA (extra formal). Same -A ending as HE. A SENHORA for women. Start formal, relax later!

o senhor/a senhora + he/she verb form

  • Using TU with a new boss — start with VOCÊ or O SENHOR.
  • Using FALAS with o senhor — o senhor takes FALA.
