A1, unit by unit

First words

Greetings: 你好

你好 (hello), 您好 (polite hello). Meeting: 初次见面 (first meeting) → 我是 + name → 很高兴认识你 (happy to know you)! Nod warmly!

WordSay itMeaning
你好nǐ hǎohello
您好nín hǎohello (polite)
早上好zǎo shang hǎogood morning
晚上好wǎn shang hǎogood evening
谢谢xiè xiethanks
对不起duì bu qǐsorry
没关系méi guān xino problem
再见zài jiàngoodbye
我是X + 很高兴认识你

我是小明 = I am Xiaoming. 是 = am/is/are (never changes!). 很高兴认识你 = very-happy-know-you!

初次见面，我是 + name
WordSay itMeaning

Watch out:
  • Saying 你好 to elders first — open with 您好!
  • Saying 我是是 — one 是 only!

Names and 你叫什么

Ask names: 你叫什么名字? (what are you called?) → 我叫… How are you: 你好吗? → 我很好! 吗 makes questions, 呢 bounces back: 我很好，你呢? (I'm fine, and you?)!

WordSay itMeaning
我wǒI / me
你nǐyou
名字míng ziname
你叫什么名字nǐ jiào shén me míng ziwhat is your name
我叫wǒ jiàoI'm called
你好吗nǐ hǎo mahow are you
请qǐngplease
好hǎogood / fine
吗 asks, 呢 bounces

你好吗? (how are you?), 你叫什么? (what are you called?). 呢 = and…?: 你呢? = And you? 我叫小红，你呢?!

…吗? → …。你呢?
WordSay itMeaning
你好吗?nǐ hǎo ma?How are you?
我很好!wǒ hěn hǎo!I'm very fine!
你叫什么名字?nǐ jiào shén me míng zi?What is your name?
Watch out:
  • Saying 我好吗 — ask OTHERS: 你好吗!
  • Forgetting 很: 我很好 (very-fine), not 我好!

Dialogue. Read it aloud twice — once for each speaker.

是 and measure words

是 and 这/那

Point! 这 (this), 那 (that). 这是书 = This is a book. Negative: 不是 (is not). Adjectives need 很: 很好 (very-good = good), 很大 (big)! 没有很 = sounds wrong!

WordSay itMeaning
这zhèthis
那nàthat
书shūbook
学校xué xiàoschool
车chēcar
大dàbig
小xiǎosmall
人rénperson
这是X · 不是 · 很 + adj

这是书 (this is a book), 那是学校 (that is a school). 不是书 (is not a book). 很大 (big), 很小 (small) — 很 required before adjectives!

这/那 + 是 + X · 很 + adj
WordSay itMeaning
这是书。zhè shì shū.This is a book.
那是学校。nà shì xué xiào.That is a school.
这不是书。zhè bú shì shū.This is not a book.
Watch out:
  • Saying 这书 — 是 required: 这是书!
  • Saying 大书 for 'big' — pair adjectives: 大书 ok, but predicate needs 很大!

Dialogue. Read it aloud twice — once for each speaker.

小红那是学校吗?nà shì xué xiào ma?Is that a school?

Measure words: 个/本

Count with MEASURE WORDS! 一个人 (one person), 三本书 (three books — 本 for books!), 两杯茶 (two cups of tea). Number + MW + noun — never skip the MW! 几 (how many, <10) vs 多少 (how many, any)!

两个liǎng getwo (things)
三个sān gethree (things)
一yīone
二èrtwo
三sānthree
很多hěn duōmany / a lot
一点yì diǎna little
Number + MW + noun

一个人 (one person), 两个苹果 (two apples), 三本书 (three books). 两 = two-before-MW (两个, not 二个)! 几个? = How many?

The BEST news: Chinese verbs NEVER conjugate! 我吃 (I eat), 你吃 (you eat), 他吃 (he eats) — same 吃! Negative: 不吃 (don't eat). Doing-now: 在吃 (am eating). Time words do everything!
