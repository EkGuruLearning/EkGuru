How the German quiz works

Every question is drawn from the EKGURU_COURSE_DE lesson bank on this site, not from a generic list. Choose a topic and a length — five questions for a short break, twenty for a proper session — and each answer comes back with a short explanation plus a link to the lesson it came from. The set rotates with the date, so the same topic gives you different questions tomorrow; that is deliberate, because recognising a question is not the same as knowing the word.

Getting the most out of a score

Read the explanations for the ones you missed before starting another round, and treat anything under half as a signal to re-read that EKGURU_COURSE_DE lesson rather than to grind more questions. Wrong answers are the useful ones — they tell you which word has not stuck yet.
