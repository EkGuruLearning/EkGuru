Subjunctive and hypotheticals

Subjunctive: जाऊँ/जाए

Wishes and maybes! मैं जाऊँ (that I go), वह जाए (that he go). चाहता हूँ कि… (I want that…), शायद… (maybe…), ताकि… (so that…)! Root + ऊँ/ए — short and sweet!

किkithat
शायदshāyadmaybe
काशkāshif only
अगरagarif
तोtothen
चाहेchāheeven if / whether
ताकिtākiso that
मानोmānoas if
Subjunctive: root + ऊँ/ए/एँ

मैं जाऊँ (I go-subj), तुम जाओ, वह जाए, हम जाएँ! चाहता हूँ कि तुम आओ (I want you to come). शायद वह आए (maybe he'll come)!

जाऊँ/जाओ/जाए/जाएँ · कि/शायद/ताकि

Dream-grammar! अगर बारिश होती, तो मैं घर रहता (If it rained, I'd stay home). अगर + past, तो + होता/रहता! वरना (otherwise), काश (if only)!

Passive and debate

Passive: खाया जाता है

Things GET done! खाना खाया जाता है (food is eaten), किताब लिखी गई (the book was written). Stem + या + जाता है! Compounds: खा लिया (ate up), कर दिया (did it)!

WordSay itMeaning
जानाjānāto go (passive aux)
सकनाsaknācan (able)
चुकनाchuknāto finish completely
डालनाḍālnāto do forcefully
खाया जाताkhāyā jātāis eaten
बनाया गयाbanāyā gayāwas made
लिखा गयाlikhā gayāwas written
समझा गयाsamjhā gayāwas understood
Stem + या जाता है · compounds

खाना खाया जाता है (food is eaten), घर बनाया गया (house was built). Compounds: खा लिया (ate it up — for self), खा दिया (ate it up — away)!

या जाता है · root + लिया/दिया
WordSay itMeaning
खाना खाया जाता है।khānā khāyā jātā hai.Food is eaten.
मैंने खाना खा लिया।mainne khānā khā liyā.I ate up the food.
किताब लिखी गई।kitāb likhī gaī.The book was written.
Watch out:
  • Saying खाना खाता है for passive — passive: खाया जाता है!
  • Mixing लिया/दिया: लिया = for-self, दिया = away!

Storytelling: एक बार

Graduation! एक बार (once), एक दिन (one day), अचानक (suddenly), आखिरकार (at last), अंत में (in the end). Mix tenses: गया, खा रहा था, खाऊँगा! Tell YOUR Delhi story!

Story spine: एक बार…अंत में

एक बार…एक दिन…अचानक…आखिरकार…अंत में — the five-beat Hindi story spine. Mix गया + खा रहा था + खाऊँगा!

एक बार → एक दिन → अचानक → अंत में
WordSay itMeaning

अंत में मैं घर आया।ant men main ghar āyā.In the end I came home. (boy)
Watch out:

  • Using only गया — mix रहा था + गा + ने!

The B2 test — 10 items

The level test closes the level. Answers are shown; in the course player the same test decides whether the next level unlocks.

  1. translate into the languageSay (boy): I want you to come

    Show the answer

    मैं चाहता हूँ कि तुम आओ

  2. translate into the languageSay (boy): If it rained, I'd stay home

    Show the answer

    अगर बारिश होती, तो मैं घर रहता

  3. choose'Food is eaten'

    1. खाना खाता है
    2. खाना खाया जाता है
    3. खाना खा लिया
    4. खाना खाएगा
    Show the answer

    खाना खाया जाता है

  4. translate into Englishइसके अलावा, मेट्रो सस्ती है!

    Show the answer

    Besides, the metro is cheap!

  5. fill the gapशायद वह ___। (come-subj)

    Show the answer

    आए

  6. choose'The guest is god'

    1. मेहमान अच्छा है
    2. अतिथि देवो भव
    3. पधारिए खाइए
    4. चाय लीजिए
    Show the answer

    अतिथि देवो भव

  7. put it in orderOrder: हुई / बारिश / अचानक

    Show the answer

    अचानक बारिश हुई

    Show the answer

    पधारिए! खाना खाइए!

    Show the answer
