A note on the Hindi spellings

Devanagari is easy to get slightly wrong when it is typed by hand — a missing matra, the wrong nukta. If a word looks off to you, trust a native speaker over these pages and please tell us so it gets fixed. Romanised spellings are a guide to the sound, not a standard: Hindi has no single agreed romanisation, so you will see shukriya and shukriyaa both used.
