Hindi Barakhadi: the Ka-Kaa-Ki-Kee Chart

A free guide from EkGuru · updated 2026-09-14

A note on the Hindi spellings

These guides are written and typed by hand, and Devanagari is easy to get slightly wrong — a missing matra, the wrong nukta, a halant in the wrong place. If a word here looks off to you, trust a native speaker over this page, and please tell us so it gets fixed. The romanised spellings are a guide to the sound, not a standard — Hindi has no single agreed romanisation, so you will see shukriya and shukriyaa both used.

बारहखड़ी (baaraakhadee) means “twelve writing” — every consonant married to twelve vowel signs. One chart, and the whole reading system clicks: if you can read क का कि की, you can read any consonant the same way, because the twelve signs never change. This is the single highest-value page on this site for a beginner. Barakhadi in English and Hindi both — every form below carries its roman sound, its Hindi name, and a speaker button.

The twelve matras by name

A vowel standing alone is a full letter (आ, ई). Glued to a consonant it shrinks into a मात्रा (matra, sign). Twelve signs to memorise — that is the whole list:

How to climb

  1. One ladder a day. Read every card aloud before you flip it — no silent peeking.
  2. Matra first. On ladders 3–4, name the sign out loud (“खा — ा!”) before reading the word.
  3. Write what you read. Copy each ladder into a notebook; the ladders double as dictation.
  4. Then graduate. Ladders done? Write your name next — it uses everything on this page.

Quick check

What does बारहखड़ी literally mean?

“Twelve writing” — twelve vowel signs applied to every consonant. Learn the twelve once, read everything.

How is खा built?

ख wearing the ा matra. Spot the sign first, then read — that habit is the whole technique.

Why ladders before sentences?

Two letters, then three; no matra, then matra. Each ladder adds exactly one difficulty, so you always know what went wrong.
