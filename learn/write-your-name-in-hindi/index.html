How to Write Your Name in Hindi — With the Full Letter Guide

A free guide from EkGuru · updated 2026-09-11

A note on the Hindi spellings

These guides are written and typed by hand, and Devanagari is easy to get slightly wrong — a missing matra, the wrong nukta, a halant in the wrong place. If a word here looks off to you, trust a native speaker over this page, and please tell us so it gets fixed. The romanised spellings are a guide to the sound, not a standard — Hindi has no single agreed romanisation, so you will see shukriya and shukriyaa both used.

Writing your name in Hindi is the single most satisfying first step in learning Devanagari, and it takes about ten minutes. You are not translating the name — names do not translate — you are transliterating: writing the same sounds using Hindi letters.

The rule that makes it work

Every Hindi consonant already contains a short "a". So क is not "k" but "ka". To write a consonant without that vowel you add a small stroke underneath called halant: क् is a bare "k".

This one fact explains almost every mistake beginners make.

Worked examples

SARAH → sa + ra → सारा. The final h is silent in English, so it is dropped. Written सारा, not साराह.

JOHN → jo + n. The n has no vowel after it, so it needs halant: जॉन. The ॉ mark writes the English "o" of hot, which Hindi does not otherwise have.

DAVID → de + vi + d → डेविड. Note the hard ड, because the English D is closer to Hindi ड than to द.

MARIA → ma + ri + yaa → मारिया. A य appears between the i and a, because Hindi does not like two vowels colliding.

ALEX → a + le + ks → ऐलेक्स. The x becomes क्स, since Devanagari has no single x.

EMMA → e + maa → एमा. Double letters in English are usually written once in Hindi.

MOHAMMED → mo + ha + m + mad → मोहम्मद. Here the double m is real and is written with a conjunct म्म.

The four mistakes everyone makes

  1. Forgetting the halant. Writing "John" as जोन reads "jona". The n needs to be bare.
  2. Using द for an English D. द is the soft dental d of Spanish donde. English D is ड. Same for त and ट.
  3. Writing silent letters. Hindi writes sound, not spelling. The h in Sarah, the e in Kate, the k in Knight — none are written.
  4. Doubling letters that are not doubled in speech. Emma has one m sound, so एमा.

Names that already exist in Hindi

Some names have a traditional Indian spelling that is not a straight transliteration, and using it is more natural:

Mary → मरियम · Joseph → यूसुफ़ · Alexander → सिकंदर · Michael → माइकल · Jesus → ईसा

Check your work

Read your name back aloud, letter by letter, adding the hidden "a" to any consonant that has no matra and no halant. If it sounds like your name, it is right. If it has an extra "a" somewhere, you have missed a halant.

What is Devanagari?

The script Hindi is written in — Devanagari is the script Hindi is written in — an abugida where consonants carry an inherent “a”.

Why can't English names always be written exactly?

Hindi writes sounds, not spellings — Hindi letters represent sounds, so a name is written the way it sounds, not the way it is spelt in English.
