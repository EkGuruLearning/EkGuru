Malayalam practice worksheet

Five questions from the free Malayalam course on EkGuru. The answers stay on screen below — the printed sheet never carries the answer key. Press Make worksheet for a fresh set, or print this one as it is.

Name   Date

1. What does നമസ്കാരം mean?

2. What does നന്ദി mean?

3. Someone asks 'നിങ്ങളുടെ പേരെന്താണ്?' — you reply…

4. The letter ക sounds like…

5. മൂന്ന് means…

Answers (on screen only — never printed)

1. hello! — നമസ്കാരം (namaskāram) is the respectful Malayalam hello — any time of day.

2. thank you — നന്ദി (nandi) is thanks — short, warm, everywhere.

3. എന്റെ പേര് … — നിങ്ങളുടെ പേരെന്താണ്? = what's your name — answer എന്റെ പേര് … (my name is …).

4. k as in kite — ക (ka) is a plain k — ഖ (kha) is the breathy one.

5. 3 — ഒന്ന് രണ്ട് മൂന്ന് — 1, 2, 3.

How the Malayalam worksheet is built

Choose a topic and a number of prompts, and the builder lays out a printable Malayalam worksheet with writing space and an answer section at the end. It is designed for paper: one topic per sheet, prompts in a readable size, answers on their own block so they can be folded away. Printing from the browser prints just the sheet, with the watermark and this site's name kept on it.

Marking and reusing a sheet

Write your answers first, then check them against the answer block and note which ones needed a second attempt — those are the words to review tomorrow. Nothing is stored for you, so print a fresh sheet for a fresh attempt; a set of five finished sheets makes an honest revision pack.

The score is a recognition score, not a fluency measure — nothing here is a certified test.
