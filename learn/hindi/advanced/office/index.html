Dialogue — In the office

Boss: मीरा, रिपोर्ट आई? (Meera, report aayi?)
Meera, has the report come?

Meera: जी सर। फ़ाइल आपकी मेज़ पर है। (Ji sir. File aapki mez par hai.)
Yes sir. The file is on your table.

Boss: अच्छा। इसका प्रिंट निकालो। (Achha. Iska print nikaalo.)
Good. Take a print of it.

Meera: ठीक है सर। और कुछ? (Theek hai sir. Aur kuch?)
Okay sir. Anything else?

Quick check

वेतन means…

salary — वेतन (vetan) = salary; दिहाड़ी = daily wages.

Which is 'computer'?

कंप्यूटर — कंप्यूटर = computer.

'समय पर आइए' means…

arrive on time — समय पर आइए — समय = time.

Say you need leave tomorrow. You say…

कल मुझे छुट्टी चाहिए — कल मुझे छुट्टी चाहिए — चाहिए = need.

दस्तख़त means…

signature — दस्तख़त (dastakhat) = signature.

Which is 'photocopy'?

ज़ेरॉक्स — ज़ेरॉक्स = photocopy.

'काम ख़त्म हुआ' means…

the work is done — काम ख़त्म हुआ — ख़त्म = finished.

Say 'send the email'. You say…

ईमेल भेजिए — ईमेल भेजिए = send the email — भेजना = to send.

छुट्टी means…

leave — छुट्टी (chhutti) — leave; कल मुझे छुट्टी चाहिए.

'शाबाश!' means…

well done! — शाबाश! — praise for good work.
