How to use this checklist

Tick a Telugu lesson only when you could explain it to somebody else, not when you have read it once. The list follows the course order for a reason: each unit assumes the one before it, and skipping the script lessons makes the later vocabulary much harder than it needs to be. If a lesson's quiz went badly, leave the tick off and repeat it after a night's sleep — spaced repetition is doing the work, not the checkbox.
