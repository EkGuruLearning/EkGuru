Telugu vocabulary

High-frequency words grouped by meaning. Learn each group, then test it in the quiz.

Family

EnglishHindi TeluguSay it
motherमाँఅమ్మamma
fatherपिताనాన్నnānna
elder brotherबड़ा भाईఅన్నanna
Telugu splits siblings by age — అన్న (elder) vs తమ్ముడు (younger)
younger brotherछोटा भाईతమ్ముడుtammuḍu
elder sisterबड़ी बहनఅక్కakka
younger sisterछोटी बहनచెల్లిchelli
sonबेटाకొడుకుkoḍuku
daughterबेटीకూతురుkūturu
husbandपतिభర్తbharta
wifeपत्नीభార్యbhārya
friend (male)दोस्तస్నేహితుడుsnēhituḍu
friend (female)सहेलीస్నేహితురాలుsnēhiturālu
familyपरिवारకుటుంబంkuṭumbaṁ

Colours

EnglishHindi TeluguSay it
redलालఎరుపుerupu
Colours never change for gender or number — say them as listed
blueनीलाనీలంnīlaṁ
greenहराఆకుపచ్చākupachcha
yellowपीलाపసుపుpasupu
whiteसफ़ेदతెలుపుtelupu
blackकालाనలుపుnalupu

Core nouns

EnglishHindi TeluguSay it
bookकिताबపుస్తకంpustakaṁ

schoolस्कूलబడిbaḍi

studentछात्र / छात्राవిద్యార్థిvidyārthi
carगाड़ीకారుkāru
roadसड़कరోడ్డుrōḍḍu
moneyपैसाడబ్బుḍabbu
dayदिनరోజుrōju

loveप्यार करनाప్రేమించడం (prēmin̄chaḍaṁ)ప్రేమిస్తాను (prēmistānu)

buyखरीदनाకొనడం (konaḍaṁ)కొంటాను (konṭānu)
learnसीखनाనేర్చుకోవడం (nērchukōvaḍaṁ)నేర్చుకుంటాను (nērchukunṭānu)
drinkपीनाతాగడం (tāgaḍaṁ)తాగుతాను (tāgutānu)
