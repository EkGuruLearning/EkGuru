How the review queue works

Every practice lab on this site feeds one queue: a wrong answer moves the item into an earlier box so it comes back sooner, a right answer moves it later. The queue lives in your browser's local storage on this device only — nothing is uploaded, and clearing site data resets it.

Use it for five minutes, not fifty

Short daily reviews beat long monthly ones, because memory consolidates between sessions. If a word comes back wrong three times, open the guide it came from rather than grinding the same item again — the queue makes weak spots visible; it cannot fix them by itself.
