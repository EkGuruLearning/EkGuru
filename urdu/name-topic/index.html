Write your name in Urdu

Rahul becomes راہل — spell, write and own your name in Urdu.

🔊 Tap any speaker button to hear Urdu spoken. Too fast or slow? Use the speed button at the bottom-right of the page.

Names transliterate by ear: break yours into sounds, match each to Urdu letters — روی (Ravi), لکشمی (Lakshmi), کرن (Kiran) show the pattern. Say it slow, write it true — سپیلنگ (spelling) by sound, not by English letters.

Rich sounds get deep letters: خ for khabar-sounds (خبر), ف for phone (فون), ژ for television (ٹیلی ویژن). These deep letters are Urdu's pride — use them proudly for every rich sound.

Introductions pair speech and script: تعارف (introduction) — میرا نام (my name is), spoken, then written. نام والے بورڈ (name boards) on doors and desks teach daily — read every board, collect every name.

Nicknames warm everything: پیار کا نام (nickname) — بچو (dear child), سونا (golden one), گڑیا (little doll). Urdu shortens with love: Ravi becomes روی, Simran becomes سمی. Earn an Urdu nickname and you have arrived.

A note on راہل. Foreign names glide in Urdu script — Rahul appears as راہل, sometimes راہول with a longer vowel. All are read Rahul; none is wrong. Urdu welcomes foreign names with flexible spelling — pick the shape you love and own it.

Questions learners ask

How do I write my name in Urdu?

Sound it out in Urdu letters: Rahul → راہل, Priya → پریا, John → جان. Urdu spells by ear — say your name slowly, catch each sound, write each letter.

What about difficult sounds?

Special letters — خ (kha), غ (gha), ق (qa), ژ (zha) — handle rich sounds. فون (phone), خبر (news) — deep letters for deep sounds, fully Urdu now.

How do I introduce my name?

پہلا حرف (first letter) starts it, آخری حرف (last letter) ends it. Introduce with میرا نام (my name is), then write it — introductions stick twice as well written.
