# EkGuru Hindi — Book 04: उन्नत हिंदी

Independent Class 7–9-inspired academic Hindi draft, not an accredited school qualification or reviewed board textbook. Entry: Book 03 or equivalent reading, writing and grammar competency.

## Contents
4 phases, 40 chapters, 80 independently authored lessons; 480 vocabulary occurrences (including revision), 320 short example lines, 20 original reading passages with 60 comprehension questions, 56 topic-specific multiple-choice labs, 21 interactive visual grammar/rhetoric models, 10 final multiple-choice exercises, a final self-review rubric, 80 optional typed writing workspaces, 40 printable worksheets and 165 generated HTML pages. 141 SVG files: 131 earlier shared illustrations, 10 new contextual vector scenes. Some abstract topics use sentence models rather than pictures. These are vector illustrations, not photographs. The short reading passages are exercises, not a complete historical literature anthology.

## Preview
Extract the ZIP. Run `python3 -m http.server 8000 --directory site` from the extracted package directory. Open `http://localhost:8000/learn/hindi/advanced/`. The standalone `preview-lesson.html` is Chapter 21 Lesson 2 with internal links disabled; full navigation is available in the site directory. Audio uses a device Hindi speech-synthesis voice, when available, not native recordings. Drafts are saved only on explicit request in the browser; local storage availability varies. The word counter uses whitespace-separated tokens, not a linguistic Hindi tokenizer.

## Integration
Target `/learn/hindi/advanced/`. The existing landing page and legacy advanced modules must remain accessible. The installer defaults to a read-only preflight. Run `python3 install.py /path/to/EkGuru --keep-existing-root`; review the result, then use `python3 install.py /path/to/EkGuru --keep-existing-root --apply`. It adds new or identical files, refuses non-identical collisions, and does not replace the existing landing page. If the destination has changed, reconcile its current generator and route ownership manually; never force-copy over existing content. See migration.md. Connect Book 03 → Book 04 → Book 05 when the latter exists and passes review. Until then the end link returns to the Hindi hub. Register the new course in the existing Hindi catalogue only after verifying the integrated routes.

Keep the source, installer, tests, preview and archive in the private development tree; do not publish them. The static pages are noindex, follow pending the existing indexing approval. Merge the shared site shell, theme, consent, analytics, local progress, accessibility and publication contracts through the existing owners. The standalone CSS and JS have distinct names for safe staging; consolidate common code into the unified textbook reader rather than retaining separate engines indefinitely. Reuse identical artwork at its existing paths. No new runtime dependency, paid API, account or payment service.

## Rebuild
`python3 source/build_art.py` regenerates the 10 new illustrations and scene map. `python3 source/build.py` generates the book using curriculum.txt, passages.txt, labs.json and visual-models.json. `python3 source/preview.py` makes the standalone sample. lab-data.txt is the authored source reference; synchronize labs.json if it changes. Earlier illustrations are bundled, not regenerated here.
