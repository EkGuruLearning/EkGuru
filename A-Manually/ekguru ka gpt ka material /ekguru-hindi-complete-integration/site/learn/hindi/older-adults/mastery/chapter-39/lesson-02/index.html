CHAPTER 39 / LESSON 02

संपादन और शैली सुधार

Editing & clarity · Use it in conversation

Device Hindi voice required; not a native recording.

बातचीत

Listen and roleplay
Aयह सूचना अस्पष्ट क्यों है?yah soochna aspasht kyon haiWhy is this notice unclear?
Bइसमें केवल जल्द लिखा है।ismein keval jald likha haiIt only says soon.
Aक्या तारीख लिख सकते हैं?kya taareekh likh sakte hainCan we write the date?
Bहाँ, इससे समय स्पष्ट होगा।haan, isse samay spasht hogaYes, that will make the timing clear.

समझ जाँचें

Check understanding
Which change improves clarity in जल्द आएँ?

Specify the date or time if known.

Which reply follows the first line of this model dialogue?

Answer

इसमें केवल जल्द लिखा है।
