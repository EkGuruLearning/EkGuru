2. शैली और संबोधन का अनुवाद

क. उदाहरण लिखिए, फिर अपना एक उदाहरण बनाइए।

कृपया थोड़ी देर प्रतीक्षा करें।

ख. कृपया बैठिए किस तरह का स्वर दिखाता है?

ग. सही अर्थ / शब्द जोड़ो।

  1. शैली __________
  2. आदर __________
  3. अनुरोध __________
  1. request
  2. respect
  3. register

घ. Please wait और Can you help me के दो अलग संबोधन वाले रूप लिखें।

2. शैली और संबोधन का अनुवाद

शैली — register · आदर — respect · अनुरोध — request

पठन-बोध

वाक्य का आशय क्या था? — सहायता माँगना।

दो हिंदी रूप क्यों संभव हैं? — संबोधन और संबंध के अनुसार शैली बदल सकती है।

शाब्दिक अनुवाद क्यों अनुपयुक्त हो सकता है? — क्योंकि मुहावरे का आशय शब्दों के सीधे अर्थ से अलग होता है।
