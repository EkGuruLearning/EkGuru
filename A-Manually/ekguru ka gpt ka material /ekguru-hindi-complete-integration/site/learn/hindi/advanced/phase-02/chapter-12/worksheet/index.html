वाक्य के उपवाक्य

Printable practice sheet

नाम: ____________________   दिनांक: ______________

1. मुख्य और आश्रित उपवाक्य

क. उदाहरण लिखिए, फिर अपना एक उदाहरण बनाइए।

जब समय मिलेगा, तब पढ़ूँगा।

ख. जब बारिश रुकी का कार्य?

ग. सही अर्थ / शब्द जोड़ो।

  1. उपवाक्य __________
  2. मुख्य __________
  3. आश्रित __________
  1. dependent
  2. main
  3. clause

घ. चार वाक्यों में क्रिया तथा मुख्य और आश्रित खंड पहचानें।

2. संज्ञा, विशेषण और क्रियाविशेषण उपवाक्य

क. उदाहरण लिखिए, फिर अपना एक उदाहरण बनाइए।

यदि प्रयास करोगे, तो सीखोगे।

ख. यदि समय मिले क्या बताता है?

ग. सही अर्थ / शब्द जोड़ो।

  1. संज्ञा __________
  2. विशेषण __________
  3. क्रियाविशेषण __________
  1. adverbial function
  2. adjectival function
  3. noun function

घ. तीनों प्रकार के आश्रित उपवाक्यों का एक-एक उदाहरण लिखें।

उत्तर कुंजी · Answer key

1. मुख्य और आश्रित उपवाक्य

समय बताने वाला आश्रित उपवाक्य।

उपवाक्य — clause · मुख्य — main · आश्रित — dependent

2. संज्ञा, विशेषण और क्रियाविशेषण उपवाक्य

शर्त, इसलिए क्रियाविशेषण उपवाक्य।

संज्ञा — noun function · विशेषण — adjectival function · क्रियाविशेषण — adverbial function
