शर्त और संभावना

Conditions & uncertainty

Name: ____________________ Date: ____________

1. Write the Hindi phrase

If it rains, then

Perhaps there will be a delay.

It is possible that

If there were time

2. Respond to the situation

Planning an outdoor visit.

अगर बारिश हुई तो क्या करेंगे?

Does शायद express certainty?

3. Independent task

Make a plan with two contingencies and one explicitly uncertain prediction.

Model answers (open before printing if needed)

अगर बारिश हुई तो — If it rains, then

शायद देर हो जाए। — Perhaps there will be a delay.

संभव है कि — It is possible that

अगर समय होता — If there were time

Model reply: हम संग्रहालय जा सकते हैं।

No, possibility or uncertainty.

Independent response varies; review accuracy, clarity and appropriateness.
