2. Respond to the situation

Which expression asks someone to repeat?

3. Independent task

Roleplay not understanding a price, and ask for clarification twice politely.

Model answers (open before printing if needed)

कृपया — Please

माफ़ कीजिए। — Excuse me.

मुझे समझ नहीं आया। — I did not understand.

फिर से बताइए। — Please explain again.

Model reply: आपको क्या चाहिए?
