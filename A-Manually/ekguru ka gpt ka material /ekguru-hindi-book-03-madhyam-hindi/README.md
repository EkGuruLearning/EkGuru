# EkGuru Hindi — Book 03: मध्यम हिंदी

Independent Class 4–6-inspired academic Hindi draft. Not a school-board equivalence, accredited qualification, or native-speaker-reviewed textbook. Intended for learners who have completed Book 02 or demonstrate comparable literacy and basic grammar.

## Contents
4 phases, 40 chapters, 80 original lessons with 480 vocabulary occurrences (including revision), 323 short reading/example lines, 20 additional original extended readings with 60 comprehension questions, 53 interactive language labs, 16 animated visual grammar models, 10 final multiple-choice exercises, an independent writing/speaking self-review rubric, 40 printable chapter worksheets, 165 generated static HTML pages, and 131 local SVG files (119 shared from earlier books, 12 new context illustrations). Some abstract concepts are presented with text and animated sentence models, not misleading decorative images. The artwork is original vector artwork, not photographs. Coverage is selective.

## Preview
Extract, enter the extracted package directory and run `python3 -m http.server 8000 --directory site`.
Open `http://localhost:8000/learn/hindi/intermediate/` for the entire course. `preview-lesson.html` is a self-contained sample of Chapter 21 Lesson 2, with internal navigation intentionally disabled. Use the full site for actual navigation.

## Rebuild
`python3 source/build_art.py` (regenerates 12 new scene SVGs and scene manifest), `python3 source/build.py` (uses curriculum.txt, passages.txt, labs.json, visual-models.json and existing art manifests), `python3 source/preview.py`.
`source/lab-data.txt` is the authored source reference; `labs.json` is the runtime build input. If changing one, synchronize the other. Shared earlier artwork is bundled, not regenerated by this package.
