# Administering PDFs via Google Sheet

## Where PDFs live

PDFs are configured in a single Google Sheet — the same spreadsheet
EkGuru already uses for payments (`SPREADSHEET_ID`
`1u5Jkbe_2lMoLWsaDPQkxTWhNACewRaOyZLLANy2dfVI` or whatever ID is in
Script Properties). The gateway adds and manages two tabs:

| Tab | Purpose |
| --- | --- |
| `Pdfs`   | One row per published or draft PDF. |
| `Config` | Operational key/value config. Holds `TELEGRAM_API_ID` and `TELEGRAM_API_HASH` only. **Never** store `TELEGRAM_SESSION` here. |

## `Pdfs` columns

| Column | Type | Notes |
| --- | --- | --- |
| `public_id` | string | Stable public id; generated by server if empty. |
| `course_id` | string | e.g. `reasoning`, `maths`, `english`. |
| `title` | string | Public title. |
| `category` | string | Category tag for filtering (defaults to course_id). |
| `telegram_pdf_url` | string | **Server-side only.** Public `t.me/...` link. Never sent to browsers. |
| `published` | bool | `true`/`false`; only `true` rows are served publicly. |
| `sort_order` | number | Lower values first in the library. |
| `description` | string | Short card description. |
| `filename` | string | Override download filename (optional). |
| `created_at`, `updated_at` | timestamp | Auto-managed. |

## Admin UI

Open `/admin-pdfs.html` (same token as other admin operations).
The flow is:

1. Enter / save the `SHEETS_INGEST_TOKEN` (stored in browser localStorage only).
2. Pick Course, enter Title, Category, Telegram public PDF URL, optional description.
3. Click **Save / Publish**. The server:
   - parses the Telegram URL,
   - connects via MTProto and verifies the message exists and is a non-protected PDF,
   - writes/updates the row in the `Pdfs` tab (or the local `data/pdfs.json` fallback when Apps Script is unreachable),
   - invalidates cache and refreshes the admin list.
4. The PDF appears at `/courses/pdfs/` within 60 seconds (SHEET_CACHE_TTL_MS).

## Manual edits

You can also edit the `Pdfs` tab directly in Google Sheets and hit
**Refresh** in the admin UI — or simply reload `/courses/pdfs/` after
the cache TTL (default 60s). Remember:

- Set `published` to `true` for a PDF to be visible publicly.
- The Telegram URL must be a public `https://t.me/<user>/<msg_id>` or
  private-channel `https://t.me/c/<id>/<msg_id>` link pointing to a
  message that contains exactly one PDF document.
- Messages with Telegram "protect content / no forwards" are rejected
  by the server (403).

## Why not a separate database?

The Sheet is the source of truth because it already powers tutor and
payment admin. Adding another DB would duplicate operational
knowledge and create another place credentials and content get out of
sync. The server caches the `Pdfs` tab for 60s to keep traffic low.
