Languages of Indonesia

The languages of Indonesia at a glance: Indonesian is the official language. The largest mother tongues here are Javanese, Sundanese, Madurese, Minangkabau, Buginese. Linguists count roughly 700 living languages in Indonesia; this guide lists the major ones individually.

Regional		bbc≈2M L1LatnN. Sumatra ~2M (Toba highlands + Medan). NO Batak macro code exists (btk absent from SIL — verified) — sisters (Karo btx, Simalungun bts, Angkola akb, Mandailing btm, Dairi btd) are separate codes, long-tailed. Batak-script (Surat Batak) heritage.

Regional		bug≈5M L1BugiSouth Sulawesi ~5M + seafaring diaspora (MY/SG/Borneo). Lontara (Bugi) script still seen — the pack hook. Pinisi-boat culture.

Javanese
Basa Jawa
Regional		jav≈85M L1LatnL1 ~85M+ (Java + transmigration + Suriname/MY/SG diaspora!). 639-1 'jv' (SIL). Speech levels (ngoko/madya/krama) — teach the sociolinguistics, not just words. Javanese script heritage (Latin dominant now).
Madurese
Basa Madura
Regional		mad≈15M L1LatnMadura + E. Java + Kalimantan diaspora ~15M. Famous for... being famously blunt (record the stereotype as linguistics, gently: direct speech style). Latin + Pegon heritage.
Makassar
Basa Makassar
Regional		mak≈2M L1LatnSW Sulawesi ~2M. SIL spells 'Makasar'. Lontara script shared with Buginese (same script, different language — say it plainly). Gowa-Tallo history.
Minangkabau
Baso Minangkabau
Regional		min≈8M L1LatnWest Sumatra ~8M + rantau (wandering-merchant) diaspora across ID/MY/SG. msa member (closest to Malay proper). Matrilineal adat — the culture hook. Jawi heritage.
Sasak
Base Sasak
Regional		sas≈2.5M L1LatnLombok ~2.5M. Five dialects (Ngeno-ngene etc. — one line, not a split). Next-door-to-Bali tourism spillover.
Sundanese
Basa Sunda
Regional		sun≈40M L1LatnWest Java ~40M. 639-1 'su' (SIL). Own script heritage (Aksara Sunda revival in Bandung signage — nice pack hook). Speech levels like Javanese, gentler.
