# EkGuru — AdSense Recovery / Original Content / Full Reachability / Human-Edited Quality Master Command

## OBJECTIVE

Production:
https://ekguru.shop/

Old domain:
https://ekgurulearning.github.io/EkGuru/

Current known state from the latest engineering audit:
- 542/542 live URLs crawled successfully
- 312 real-browser layouts tested
- prior mobile and desktop overflow/navigation bugs were found and fixed
- CI/regression checks exist
- one remaining production/domain issue was identified around GitHub Pages → HTTP → HTTPS migration and must be verified/fixed
- `manifest.webmanifest` still had an old `/EkGuru/` path and was fixed in the audit

DO NOT ASSUME THIS MEANS ADSENSE IS READY.

The next objective is to make the actual publisher content substantially stronger, more original, more useful, better organized, and fully reachable.

IMPORTANT:
Do not try to “trick” Google into believing AI-written text is human-written.
Do not use AI-detector evasion, hidden text, synonym spinning, fake author identities, fake experience, fabricated reviews, or fabricated facts.

Instead:
- create genuinely original content
- add useful human editorial judgment
- add real examples
- add original explanations
- add original exercises
- add original tools/functionality
- add transparent authorship where appropriate
- fact-check claims
- remove duplicated/thin content
- make every important page useful on its own

Google's current AdSense guidance emphasizes unique/relevant content, clear navigation, sufficient content, and a good user experience. It also warns against scraped/replicated and auto-generated pages with little or no original value.

PHASE 3 — HUMAN-EDITED ORIGINALITY AUDIT
==================================================

The goal is NOT to pass an “AI detector”.

The goal is to make pages genuinely original.

For every important page identify:

1. What useful question does it answer?
2. What does EkGuru explain that a generic competitor does not?
3. What original examples exist?
4. What practical task can the user complete?
5. What mistakes does EkGuru explain?
6. What learner context does the page add?
7. What original exercise/tool is available?
8. What source/fact verification is needed?
9. Is the wording natural and specific?
10. Is the page merely a template with swapped keywords?

Flag pages with:
- generic introductions
- repetitive AI-style filler
- identical paragraph patterns
- excessive headings with little substance
- generic conclusions
- keyword stuffing
- synonym-spun content
- repeated FAQ blocks
- fake personal experience
- fake “expert” claims
- unsupported statistics
- invented examples
- contradictory facts
- copied external text
- near-duplicate paragraphs across pages
- machine-translated awkward wording
- content that could exist on any language-learning site
