# Turkey Language Inventory — Deep Audit (Phase 6)

Batch: western-asia (pass 1) · Status: PRELIMINARY · Date: 2026-09-14

Turkey combines the longest census-language blackout in the inventory (no
mother-tongue question since 1965) with the most politically loaded
demographics (Kurdish/Zaza figures are contested by all sides). This file is
the Phase 6 deep audit: the Art.3/Art.42 backbone + 2000s reforms, the
1965-blackout artefact, and the Mardin-Arabic + Laz rulings pass 2 must make.
Figures-only throughout — no identity adjudication anywhere in this file.

## 3. Gap analysis (EkGuru coverage)

- P1 plan for tur is correct (state language 82M + CY official + diaspora).
- kmr (12M) is the largest `none` in Western Asia — promotion watch only;
  figure disputes (±3M) make it a pass-2-first case.
- **Mardin Arabic gap**: Mesopotamian Arabic (`acm`, Mardin/Siirt — likely
  500K–1M) is NOT entered; the apc entry covers Levantine only. Entry

- **Laz gap**: Laz (`lzz`, Rize/Artvin Black Sea — ~200K) is NOT entered;

## 4. Constitutional backbone (what the entries cite)

- Constitution Art.3: Turkish is "the language of the State" (unamendable
  provision); Art.42: no language other than Turkish as mother tongue in
  education — the legal ceiling that still stands.
- 2000s reforms inside the ceiling: private Kurdish courses (2004), TRT
  Kurdî public channel (2009), elective Kurdish/Zaza/Laz/Adyghe/Georgian/
  Abkhaz in state schools (2012+), Kurdish in courts (2013, interpreter
  scheme), place-name restorations (patchy).
- Lausanne Treaty minorities (Armenian/Greek/Jewish school rights) are the
  only internationally-treatied language rights — correctly long-tail.

## 5. The 1965 blackout + refugee mix (artefacts — read nothing at face value)

1. **1965 blackout**: six decades without a mother-tongue census means ALL
   minority figures are KONDA-survey/academic extrapolations. Kurmanji 12M
   spans published estimates of ~9–15M; the band carries the inventory's
   widest honest range, low confidence.
2. **Refugee mix**: the `apc` 4.2M folds Hatay/Urfa native Levantine
   (~1M) with Syrian-refugee Levantine (~3M, 2015–20 peak, declining with
   returns). Roles carry BOTH minority+immigrant; pass 2 must split the
   figure or drop the refugee share to a dated note.
3. **Zaza identity**: whether Dimli/Kirmanjki speakers count as Kurdish is
   contested (speakers split; censuses never asked). Entries use ISO codes
   (`diq`/`kiu`) with speaker figures only — the file takes no position.

## 6. Code treatments specific to Turkey

- **Kurmanji script split**: TR-side `kmr` uses Latin (Hawar alphabet);
  IQ/SY-side Kurmanji uses Arabic script — same code, script notes
  mandatory; learner text must pick per-market.
- **Zaza pair**: `diq` (Southern/Dimli) + `kiu` (Northern/Kirmanjki) —
  distinct codes, Zaza-macro (`zza`) NEVER used for entries.
- **Levantine vs Mesopotamian**: entry `apc` (Hatay/Urfa + refugees) vs
  missing `acm` (Mardin — §3 ruling); never folded.
- **Adyghe diaspora**: TR `ady` (250K, Western-speaking, Kayseri axis) vs
  RU `ady` homeland entry — same code, diaspora notes; the kbd/ady pair
  note (RU audit §6) applies in reverse.
- **TİD**: `tsm` (Turkish Sign Language) — distinct from Ottoman-era
  signing heritage claims; corpus TBD pass 2.
