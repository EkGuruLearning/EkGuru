# Vietnam Language Inventory — Deep Audit (Phase 6)

Batch: southeast-asia (pass 1) · Status: PRELIMINARY · Date: 2026-09-14

Vietnam pairs Southeast Asia's strongest minority-language textbook program
(MOET-approved primers in Cham, Khmer, Hmong, Bahnar, Jarai, Ede) with a
census that asks ethnicity, never language — folding the Hmong pair, the
Tai triple and the Dao cluster into single lines. This file is the Phase 6
deep audit: the Art.5 backbone, the ethnicity-fold artefact, the only
three-sign-language country in the inventory, and the Bahnaric/Katuic sweep
pass 2 must run.

## 4. Constitutional backbone (what the entries cite)

- Constitution Art.5 (2013): Vietnamese is the national + official
  language; ethnic minorities may use their own languages and scripts, and
  the state "creates conditions" for minority-language education.
- Implementation (strongest in SE Asia on paper): MOET-approved minority
  primers exist for Cham, Khmer, Hmong, Bahnar, Jarai and Ede; Khmer wats
  + Cham schools teach in-script; Hmong/Muong radio hours on VOV.
- 54-ethnicity framework: recognition is ETHNIC (Tày/Nùng/Thái/H'Mông/Dao
  ...), never linguistic — the legal root of the folding artefact (§5).

## 5. The ethnicity-fold artefact (census folds, ISO splits — split them back)

Three ethnicity lines each fold multiple entry-class codes:

1. **H'Mông 1.4M** = White Hmong (`mww`) + Green Mong (`hnj`) — distinct
   codes, limited intelligibility; entries split, census cited as the sum.
2. **Thái 2M** = Tai Dam (`blt`) + Tai Dón (`twh`) + Red Tai (long-tail) —
   distinct codes AND scripts (Tai Viet variants); entries split.
3. **Dao 1M** = Mien (`ium`, Hmong-Mien) + Hmongic + Tai components —
   NO Dao entry exists (correctly — it is an ethnicity, not a language);
   Mien threshold ruling in §8.
- Rule generalised: "ethnicity is not a language entry" (same rule as
  CN Hui/Manchu, IN audit). Any source quoting ethnicity as speakers is
  rejected in pass 2.

## 6. Code treatments specific to Vietnam

- **Muong**: `mtq` (Vietic — Vietnamese's closest sister; Hòa Bình) —
  the proof that "Vietnamese dialects" stop at the Vietic branch boundary.
- **Tay/Nung pair**: `tyz` + `nut` (Tai-Kadai; Lạng Sơn/Cao Bằng) —
  distinct codes, Zhuang-adjacent; separate entries, cross-noted.
- **Chamic triple**: `jra` + `rad` (highlands) + `cjm` (coastal, Cham
  script, Panduranga heritage) — Austronesian enclave in Austroasia.
- **Hmong pair**: `mww` + `hnj` — distinct codes; Romanized Popular
  Alphabet (RPA) script shared with LA/US diaspora.
- **Three signs**: `hab` + `hos` + `haf` — distinct codes, low mutual
  intelligibility (north/centre/south schools); the inventory's only
  3-sign country; unification pressure noted, split holds.
- **Khmer Krom**: `khm` (Mekong Delta ~1.4M; Khmer-script wats) — same
  code as KH; one pack, Krom notes.
