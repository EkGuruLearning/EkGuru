# reports/

Generated and dated reports, evidence JSON and CSV matrices written by tools in
`tools/` (for example `adsready-local.json` and the page matrix).

- Do not hand-edit anything here. Re-run the tool that writes it.
- A merge conflict in a file here is resolved by regenerating it.
- Dated human-written audits belong in `docs/audits/`, not here.
- No personal data.
